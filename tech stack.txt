Requirements for an operational deployment

1. Replace mock login with Laravel authentication and enforce Security Head,
   Security Guard, and gate permissions on the server.
2. Save visitor transactions, ID custody, incidents, lost and found records,
   personnel, duty assignments, and activity history in MySQL. Generate
   dashboard totals and security reports from those records.
3. Store uploaded photos in private file storage with authorized access.
   Keep the file references and access metadata in MySQL.
4. Configure HTTPS, environment-based secrets, and regular backups with a
   tested restore process. Use Asia/Manila for campus reporting dates.
